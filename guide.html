使用说明

面向没有生物信息学背景的使用者。全流程在本机完成，不需要命令行，也不需要联网。

一、准备输入文件

软件读取的是 FASTA 格式的流感病毒全基因组序列，一个文件里包含同一毒株的 8 个节段：

>PB2 | A/Washington/.../2025 | segment 1 | ...
AGCTTA...（核苷酸序列）
>PB1 | ...
>PA | ...
>NP | ...
>M | ...
>NS | ...
>HA | ...
>NA | ...
  • 可接受的文件后缀：.fasta、.fa、.txt。
  • 节段命名支持常见写法，软件会自动识别节段与亚型。
  • 缺节段不会中断分析，但会在质控与摘要里标出来——缺哪个节段，相应结论就不成立。
  • 一个文件里放了多个毒株时，软件会自动拆分逐个分析。

二、五步跑完一个样本

  1. 打开文件：点工具栏「📂 打开」，或按 Ctrl + O；也可以直接把 FASTA 拖到窗口里。
  2. 等自动分析跑完：软件依次完成亚型识别 → 8 节段翻译 → 位点比对 → 耐药判读 → 谱系定位。进化树不自动构建，需要时在树页签点「建树」才跑。工具栏右侧显示「✅ 全部分析完成」即为结束。
  3. 看「分析总览」：样本信息、异常位点数、耐药标记与关键发现都在这一屏。点卡片会跳到对应的详情视图。
  4. 逐个视图核对：突变位点总表看具体替换，谱系定位看它落在哪个 clade，进化树（点「建树」后）看它落在哪个分支。
  5. 导出报告：点「📤 导出」或用 Ctrl + M / D / E 出 Markdown / Word / Excel。

三、快捷键

Ctrl + O打开单个 FASTA 文件
Ctrl + B批量选择多个 FASTA 文件分析
Ctrl + M导出 Markdown 报告
Ctrl + D导出 Word 报告
Ctrl + E导出 Excel 报告
Ctrl + Q退出

样本列表里可用 ↑ ↓ 切换当前样本，右侧所有视图会跟着切换。

四、结果怎么读：五种状态

每条位点结果都带一个状态。最关键的一条是：「没读到」不是「读到了异常」。

  • confirmed —— 确认存在的替换，会进入异常统计。
  • unknown —— 读到了替换，但意义尚不明确。同样是发现，但配色与措辞与前者不同。
  • wildtype —— 读到了，与参考一致，不是发现。
  • nocall —— 这个位点根本没读到（覆盖不足、缺节段、序列截断）。它不计入异常数，也不会按发现着色。
  • info —— 提示性条目，本身不对应某个位点。

所以看到某个位点"没报"，先分清是读到了野生型还是压根没读到——这两件事在报告里含义完全不同。

结果与报告里的两类标注

除了状态，报告和界面上还可能出现两种前缀标注。它们都只说明这条结果的可信度，不改变检出：

  • ⚠️ 出处未确证 / ⚠️ 出处存疑 —— 出现在参考文献行末尾，针对的是 引用而不是位点：前者=在 PubMed 与 Crossref 里没能把这条引用认定成某篇已发表文献； 后者=多路检索（题名、作者+年份+期刊、卷页坐标当年及前后一年）全部落空，高度疑似虚构。 两种都只标注、不删除，位点照常检出。
  • ⓘ 历史位点 —— 出现在「功能影响」列，针对的是这一条突变： 该位点的参考残基至今对齐，但文献记录的替换在 2015-2026 年的分层语料里一次都没测到， 标注里会给出语料条数与该位置当前的主要残基占比。带这个标注的 unknown 多半是该位点在近年流行株里的自然多态，是否为新演化要结合亚型判断。

两类标注都会随引用行/功能影响列进入界面、Markdown、Word 与 PDF 报告； 图例目前附在 Markdown 报告的参考文献小节末尾，导出去掉界面也能看懂。

还有第三种情况，它跟前两类不一样：会改变检出

上面两类标注都只加说明、不动判定。下面这一类会，所以单独讲清楚，不混进"标注"里：

位点表里有极少数行，文献写的"参考残基"在 2026-09 审计所用的分层语料 （GenBank 按亚型 × 年代现拉：2015-2019 / 2020-2023 / 2024-2026）里一次都没有出现， 而它被标成"突变"的那个残基恰恰是该位点的众数（≥50%）。对这种行， "样本读到了它"不再携带任何信息 —— 实测每个乙型流感样本会因此在 5 个 HA 位点和 1 个 NA 位点上 各多出一条红色「确诊」，平均约 4.7 条/样本（60 条真实 B 型 HA 序列产出 284 条）。

这类残基现在不再作为确诊突变报告，改为在对应节段末尾汇成一条 info 说明，逐项列出被降级的位点、语料频率与样本量，报告末尾另附图例。三条边界：

  • 它不等于"这个样本没带那个残基"，也不等于"该位点没有变异"；位点本身仍留在表里， 等它的参考残基被真正修正后会自动恢复报告。
  • 清单由审计数据生成、可复现（mutation/majority_residue_sites.json）， 不是手工名单；入选要同时满足五条判据，逐条都带语料证据。
  • 只适用于 HA/NA 表面蛋白的抗原/结构类位点。内部节段的适应性标志 （如 PB2 627K、PB2 89V、PA 295P、NS1 42S）即使在人群里很常见也照常报告 —— 对那些位点，"样本带着它"本身就是结论；耐药位点更不受影响 （它们 0% 检出才是正常状态）。把这条规则一刀切套到所有位点上， 会把"报得多"的毛病换成"报不出"的毛病，所以我们没有这么做。

五、批量分析

  • 「📁 批量」一次选择多个文件，或一次拖入多个文件。
  • 分析完成后「群体摘要」与「时间趋势」会自动填充。
  • 批量样本数较多时建议内存 8GB 以上。
  • 某个样本失败不会带走整批：失败样本会被标出，其余结果照常产出。

六、外部工具：装了更好，不装也能跑

进化树与谱系定位支持调用外部引擎，但全部可选，缺失时软件回退到内置实现，并在界面上说明回退了什么：

  • IQ-TREE 2 —— 最大似然法建树。缺失时回退到内置 NJ 法。
  • Nextclade CLI —— 谱系定位。缺失时使用内置突变匹配分类器。
  • MAFFT —— 多序列比对，已随包捆绑。

选择压力页显示的 dN/dS 类数字来自内置 Nei–Gojobori 计数 + Fisher 精确检验；软件不运行 HyPhy FUBAR，界面上也直接写明了这一点。位点表为 Suttie 2019 八张实验验证表单源，位号靠双序列比对换算。
