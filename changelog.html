更新日志

这里列出最近 8 个版本的要点。完整的逐条历史在软件内 帮助 → 更新日志 中查看，那里随版本一起分发、不会漏项。

5.1.0

【修复】全面代码审查收口 —— 消除「把没读到的东西渲染成自信结论」这一类缺陷

  • 变异检测：同一位点的多个等位基因合并为一条结果（野生型样本不再重复列出 4 次耐药位点、不再凭空发明未知替换）
  • 结果语义统一为五态：「没读到」(nocall) 不再计入异常数、不再染红；预警引擎不再把没读到的位点报成「抗原区出现突变」
  • 裂解位点 HPAI 判据改为连续碱性氨基酸 run + 位置敏感（修复真实低致病 H5 加 1 个替换即被判高致病，避免误导扑杀与法定上报）
  • 参考序列库装载改为按内容校验（文件名与序列不符时不再静默装错亚型），并对骨架库加覆盖护栏：禁止用降级合成结果覆盖真实 IQ-TREE 产物
  • 谱系定位跑挂时不再整段消失，失败原因统一披露到全部交付面；方法归属单一来源，内置分类器 / Nextclade CLI / 树推断三者可区分
  • 进化树界面的英文残留补干净：保存/全屏树图的标题与图例、着色维度下拉框、分支徽章均已中文化
  • 选择压力页明示「未运行 HyPhy FUBAR」（实际为内置 Nei-Gojobori + Fisher），不再让人以为 dN/dS 数字出自 FUBAR
  • 删除零生产引用的第二套报告实现与死模块（两套实现对「重配章节」的答案正好相反）
  • 位点数据库收敛为单一数据源链路（schema → 生成器 → 运行时表），并加覆盖护栏
  • 安全：清除曾被误提交进仓库的 NCBI API Key，凭证改为只从环境变量读取
  • 工程：回归测试覆盖本轮全部修复；提交门禁改为每次提交都跑全量

5.0.0

【重大更新】全模块代码质量审查与优化

  • 亚型检测：修复 H7N9 信号肽误判、H15N9 子串误伤、罕见亚型保护机制
  • 突变分析：修复耐药级别三级氨基酸匹配、DMS 回退查询（命中率 0%→88%+）
  • 进化树：补齐 H5N1/H7N9/H9N2 骨架数据链路、H7N9 谱系定位恢复、标签防堆叠
  • 进化指数：修复读码框错位（锚点对齐替代盲砍信号肽）
  • 重配检测：亚型感知过滤、两阶段同源搜索、匹配缓存键修复
  • 序列质控：P0–P2 共 16 项算法修复并补单元测试
  • 参考数据库：替换错误节段、恢复被丢弃参考文件
  • 性能：重配分析提速约 3 倍；批量分析修复"卡在 60%"的管道死锁
  • 导出增强：Word/Excel 新增 DMS 注释列

4.9.0

进化树模块全面修复与优化

  • 修复序列名称截断导致的去重覆盖问题
  • 修复批量模式下点击样本会把进化树重建为单样本树
  • 修复 IQ-TREE 工具路径未传递导致静默降级为内置 NJ 法
  • 从 Nextclade 数据集重建骨架代表株序列，改用规范策略定根
  • 新增建树期间的动态进度提示与进度条，建树完成后自动切到进化树视图

4.8.1

【修复】全面代码审查，修复 33 个问题

  • 修复 25 个模块级问题（B 型裂解位点假亚型、dN/dS 路径枚举、信号肽偏移等）
  • 突变位点总表 8 项优化：清除重复条目、修复 N9 位点坐标冲突
  • 位点数据生成器新上去重校验机制，防止数据源污染
  • 耐药规则统一到单一来源，PA 巴洛沙韦条目合并

4.8.0

【架构】主窗口渐进式拆分 + 性能优化

  • 新增 WorkerManager 统一管理后台线程生命周期，CacheManager 管理分析结果缓存
  • 亚型检测从 O(n×m×L²) 优化为 k-mer 预过滤，消除每次调用重建比对器的开销
  • dN/dS 实现 Nei-Gojobori 多核苷酸路径枚举算法
  • 统一抗原位点定义来源，避免多处各存一份

4.7.0

【新功能】三大界面增强模块

  • 分析总览仪表盘：可点击卡片展示关键指标，点击跳转到对应详情视图
  • 交互式图表面板：支持网页渲染与浏览器打开双模式
  • 专业报告导出器：封面页 + 执行摘要 + 嵌入图表 + 参考文献附录

4.6.19

【修复】全面代码审计，修复 30 个问题

  • 修复 PB2/PB1 键冲突导致 PB2 永远无法被识别
  • 修复 HA1 位置 0 的边界判断导致漂移基线分析被跳过
  • 修复所有亚型都按 H3 抗原位点判读的问题，改为按实际亚型查找
  • 修复基因星座负权重被当成奖励、耐药去重失效、报告表头与数据列序不匹配
  • 清理临时文件泄漏与强制杀线程，改为合作式取消

4.6.18

  • 拆分巨型版本文件为版本号 / 变更日志 / 坐标三份，提取共享配色、异常层级、亚型推断模块
  • 耐药规则匹配从主窗口迁出，消除分析层对界面层的依赖倒置
  • 统一后分析管道，消除三处重复的四阶段调用链
