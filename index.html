方法学说明

结果是怎么算出来的，以及没算什么

分析工具的可信度来自方法的透明。以下几条明确说明每个环节的实际实现， 避免把"检测到了某个工具"读成"用了这个工具出数"。

选择压力：内置实现，未运行 HyPhy FUBAR

dN/dS 相关判读由内置的 Nei–Gojobori 计数 + Fisher 精确检验完成。未运行 HyPhy FUBAR，软件界面与导出报告中都已明示这一点；即使本机装有 HyPhy，也不会自动改用它出数。

重配与基因型分类：不依赖 BLAST+

节段来源判断走 Biopython 序列比对 + 滑动窗口同源比对与迭代分配，不需要额外安装 BLAST+，也不产生 BLAST 输出文件。

外部引擎全部可选，缺失自动降级

IQ-TREE 2 用于最大似然建树，Nextclade CLI 用于谱系定位，MAFFT 用于多序列比对（随包捆绑）。任一缺失时回退到内置实现并在界面上说明回退原因，不阻塞基础分析。

结果有五种状态，"没读到"不等于"异常"

每条位点结果取 confirmed / unknown / wildtype / nocall / info 五态之一。「这个位点没读到」(nocall) 不计入异常数、不按风险着色，与「读到了但意义未知」(unknown) 分开呈现。

待分析序列不出本机

输入的 FASTA 序列全程在本机处理，软件不向任何服务上传序列。唯一的网络行为是 3D 结构视图按需从 RCSB / EBI 拉取公开结构文件，且优先使用本地缓存。

引用与数据来源

每一条判读都能追到出处

分析工具的结论必须能被追溯。下表列出各环节实际使用的数据来源， 以及导出报告里随每条结果一起给出的文献引用是怎么组织的。

位点判读的文献依据

内置 50 条文献引用表（作者 / 年份 / 题名 / 期刊 / 卷期 / 页码）， 335 条位点记录中有 331 条挂着引用编号。 导出报告会在每条突变后给出 [ref74] Bloom JD, Gong LI, Baltimore D (2010) — Permissive secondary mutations… 这样的一行，可直接按题名检索原文。

疫苗株推荐

疫苗株对比与配方判读读的是内置疫苗数据库（当前 v2.14，2026-09-24 更新）， 来源标注为 WHO 疫苗成分推荐与 Nextclade 参考序列， 按流行季分组（2026-2027 北半球、2025-2026 北半球、2025 与 2026 南半球）， 另含 H5 / H7 / H9 参考株。

参考序列与骨架树

逐节段参考序列库经 NCBI E-utilities 从 GenBank 抓取； 系统发育骨架树由 IQ-TREE 2 在本地构建， 谱系分支定义读自随包捆绑的 Nextclade 数据集（B、H1N1pdm09、H3N2、H5 四套） 与 8 份按亚型整理的 clade 定义文件。

抗原位点与漂移基准

抗原位点定义按亚型取用，参考状态基于经典文献（Wiley 1981、Connor 1994、 Matrosovich 2000 等）；HA1 漂移基线按 H3 与 B/Victoria 分别取 Koel 2013 与 Bush 1999 的历史基准。报告里会同步给出提示：参考氨基酸反映历史性参考株特征， 对近年流行株可能已发生偏移。

3D 结构视图

结构文件按需从 RCSB / EBI 拉取公开数据，优先使用本地缓存； 除结构拉取与参考序列更新外，软件没有其他网络依赖。

外部引擎

IQ-TREE 2（最大似然建树）、Nextclade CLI（谱系定位）、MAFFT（多序列比对，随包捆绑）、 Biopython（序列比对与翻译）。四者全部可选，缺失时回退到内置实现并在界面说明， 不阻塞基础分析。

版本历史

它是怎么一路长成现在这样的

这里收录最近几个版本的主要变化，完整清单在 更新日志；软件内「帮助 → 更新日志」是权威记录。

5.1.0 当前版本

【修复】全面代码审查收口 —— 消除「把没读到的东西渲染成自信结论」这一类缺陷

  • 结果语义统一为五态：「没读到」(nocall) 不再计入异常数、不再染红
  • 裂解位点 HPAI 判据改为连续碱性氨基酸 run + 位置敏感，修复真实低致病 H5 加 1 个替换即被判高致病
  • 选择压力页明示「未运行 HyPhy FUBAR」；清除曾被误提交进仓库的 NCBI API Key

5.0.0

【重大更新】全模块代码质量审查与优化

  • 亚型检测修复 H7N9 信号肽误判、H15N9 子串误伤；序列质控 P0–P2 共 16 项算法修复
  • 重配分析提速约 3 倍；批量分析修复"卡在 60%"的管道死锁

4.9.0

进化树模块全面修复与优化

  • 修复 IQ-TREE 工具路径未传递导致静默降级为内置 NJ 法
  • 从 Nextclade 数据集重建骨架代表株序列，新增建树进度提示

4.8.1

【修复】全面代码审查，修复 33 个问题

  • 位点数据生成器新上去重校验机制，防止数据源污染

4.8.0

【架构】主窗口渐进式拆分 + 性能优化

  • WorkerManager 统一管理后台线程生命周期，CacheManager 管理分析结果缓存
  • 亚型检测从 O(n×m×L²) 优化为 k-mer 预过滤
