方法学说明

结果是怎么算出来的，以及没算什么

分析工具的可信度来自方法的透明。以下几条明确说明每个环节的实际实现， 避免把"检测到了某个工具"读成"用了这个工具出数"。

位点表单一来源，位号靠比对换算

运行时位点表为 Suttie 2019 八张实验验证表（297 行）单源。位号换算走样本与编号基准株的双序列比对；落在比对空隙里的位号一律判「未评估」并给出可见原因，不退化成「野生型」。位点分级（红/橙/黄）已彻底取消——它从来不是文献给的。

选择压力：内置实现，未运行 HyPhy FUBAR

dN/dS 相关判读由内置的 Nei–Gojobori 计数 + Fisher 精确检验完成。未运行 HyPhy FUBAR，软件界面与导出报告中都已明示这一点；即使本机装有 HyPhy，也不会自动改用它出数。

外部引擎全部可选，缺失自动降级

IQ-TREE 2 用于最大似然建树，Nextclade CLI 用于谱系定位，MAFFT 用于多序列比对（随包捆绑）。任一缺失时回退到内置实现并在界面上说明回退原因，不阻塞基础分析。

结果有五种状态，"没读到"不等于"异常"

每条位点结果取 confirmed / unknown / wildtype / nocall / info 五态之一。「这个位点没读到」(nocall) 不计入异常数、不按风险着色，与「读到了但意义未知」(unknown) 分开呈现。

待分析序列不出本机

输入的 FASTA 序列全程在本机处理，软件不向任何服务上传序列。唯一的网络行为是 3D 结构视图按需从 RCSB / EBI 拉取公开结构文件，且优先使用本地缓存。

引用与数据来源

判读能追到出处，出处也核过一遍

分析工具的结论必须能被追溯。下表列出各环节实际使用的数据来源， 以及导出报告里随每条结果一起给出的文献引用是怎么组织的。

位点判读的文献依据

内置位点表 297 行，单一来源 Suttie 2019《影响禽流感 A 病毒生物学特性的 分子标记清单》（Virus Genes）八张实验验证表。配套 330 条文献映射： 307 条带 PMID / DOI（verified），23 条标「出处未确证」 （只标注、不补全）。导出报告在每条突变后给出引用行；未确证的引用在行尾带 ⚠️ 出处未确证。标签只说明"这条依据可不可信"，不改变位点本身的检出结果。

疫苗株推荐

疫苗株对比读内置疫苗数据库，来源标注为 WHO 疫苗成分推荐与 Nextclade 参考序列， 按流行季分组。v5.2.0 起疫苗匹配去掉自造评分，改按待测株与候选株 抗原区氨基酸差异个数挑株。

参考序列与骨架树

逐节段参考序列库经 NCBI E-utilities 从 GenBank 抓取； 系统发育骨架树由 IQ-TREE 2 在本地构建， 谱系分支定义读自随包捆绑的 Nextclade 数据集（B、H1N1pdm09、H3N2、H5 四套） 与按亚型整理的 clade 定义文件。

编号帧与「未评估」

HA 用 H3 编号（H5 样本括号另给 H5 号）、NA 只给 N2 号、内部蛋白给 GD96 全长号。 位号换算靠双序列比对；落在比对空隙里的位号判「未评估」并给原因。 旧表时代那批"修补清单"（历史位点、众数残基降级等）已随位点库换代一并退役， 新表的位号由比对换算、帧参考由测试从磁盘重算核验，那两个病按构造不再发生。

3D 结构视图

结构文件按需从 RCSB / EBI 拉取公开数据，优先使用本地缓存； 除结构拉取与参考序列更新外，软件没有其他网络依赖。

外部引擎

IQ-TREE 2（最大似然建树）、Nextclade CLI（谱系定位）、MAFFT（多序列比对，随包捆绑）、 Biopython（序列比对与翻译）。四者全部可选，缺失时回退到内置实现并在界面说明， 不阻塞基础分析。

版本历史

它是怎么一路长成现在这样的

这里收录最近几个版本的主要变化，完整清单在 更新日志；软件内「帮助 → 更新日志」是权威记录。

5.2.0 当前版本

【重构】位点库换代 Suttie 2019 单源 + 产品减法收口

  • 位点表改为 Suttie 2019 八张实验验证表（297 行）单源；位号统一三套编号帧、换算走双序列比对；位点分级（红橙黄）彻底取消
  • 产品减法：重配检测、配方匹配、监测预警、风险评分、突变网络五块整体移除；疫苗匹配去自造评分改按抗原区差异个数挑株
  • 进化树不再导入即自动开建，改树页签点「建树」才跑；切换样本提速（比对结果进进程内缓存、选择压力面板挪后台）

5.1.0

【修复】全面代码审查收口 —— 消除「把没读到的东西渲染成自信结论」这一类缺陷

  • 结果语义统一为五态：「没读到」(nocall) 不再计入异常数、不再染红
  • 裂解位点 HPAI 判据改为连续碱性氨基酸 run + 位置敏感，修复真实低致病 H5 加 1 个替换即被判高致病
  • 选择压力页明示「未运行 HyPhy FUBAR」；清除曾被误提交进仓库的 NCBI API Key

5.0.0

【重大更新】全模块代码质量审查与优化

  • 亚型检测修复 H7N9 信号肽误判、H15N9 子串误伤；序列质控 P0–P2 共 16 项算法修复
  • 批量分析修复"卡在 60%"的管道死锁

4.9.0

进化树模块全面修复与优化

  • 修复 IQ-TREE 工具路径未传递导致静默降级为内置 NJ 法
  • 从 Nextclade 数据集重建骨架代表株序列，新增建树进度提示
